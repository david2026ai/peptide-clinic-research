## Two hardwired principles

1. **Needs before scores.** Discover customer needs + industry value-adds (obvious *and* latent) before locking axes. No table-stakes-only maps.
2. **Focus requires give-ups.** Name Focus + Breaker **and** 3–7 stop-investing items, then ship a SYM Demand–style multi-series attribute chart + hyper-focused segment model (Value / Deliver / Give up).

---

## What it is

A forced kickoff ritual for any vertical / offer / venture:

1. **Intake & readiness** — who pays, ICP, offer; defer if too thin  
2. **Needs + value-adds** — obvious + latent  
3. **5–8 attributes** — each `traces_to` a need/value-add  
4. **Score 1–5** — Us vs 2–4 face competitors (prefer 2); attach off-chart  
5. **Focus / Breaker / Give-ups**  
6. **Segment model** — hyper-focused audience thesis + speakable  
7. **Persist YAML** + **dynamic chart** (SVG line and/or Canvas)

**Output:** `maps/<slug>.yaml` + speakable MD + chart. **Not financial advice. Not medical advice.**

**Sibling:** Prior skill id **`casemap`** — same methodology lineage. Prefer **`attribute-map`** for new portable work; refresh existing casemap YAML in place when that slug already exists.
