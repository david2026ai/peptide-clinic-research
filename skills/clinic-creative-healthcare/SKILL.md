# Clinic healthcare creative system

Read `../../AGENTS.md`, clinical-claims filter, `clinic-legitscript-ads-gate`, Meta and Google/YouTube filters, brand-system (when present), and CaseMap/attribute-map segment. Creative without certification gates is draft only. No PHI in briefs, UGC, or tooling.

## Positioning handoff (required)
Pull from attribute-map / CaseMap:
- Audience cell + Focus (default hypothesis: decision receipt / cost clarity)
- Give-ups (no peptide spectacle, no outcome guarantees, no shame)
- Face rivals’ public pricing posture (informative—not a license to copy risky creatives)

## Creative modes
| Mode | Job | Typical inventory |
|---|---|---|
| A — Service education | Explain evaluation, independence, process | Meta general telehealth; Search; organic YT |
| B — Offer clarity | Itemized costs, renewals, exclusions | Landing + retargeting of **public** pages only |
| C — Prescription-aware | Names or implies specific Rx products | Only after LS + platform Rx paths |
| D — HOLD / BLOCKED | Experimental peptides, RUO funnels, guaranteed Rx, shame | Do not produce “almost compliant” versions |

## Brief template
1. Platform + inventory (Meta feed/stories, Search, Demand Gen, paid YT, organic YT)
2. Mode A/B/C/D and certification prerequisites
3. Exact product status (approved / compounded / off-label / unapproved)
4. Claim list with evidence IDs from claims register
5. Hook / body / CTA / disclaimer text
6. Visuals: talent, props, overlays, thumbnails (each is a reviewable variant)
7. Destination URL + mirror of on-page claims
8. Audience class (see `clinic-audience-targeting`)—no patient lists
9. HOUSE vs PLATFORM vs REG labels on every risky line

## Hook / copy rules
- **Allowed pattern:** service + process + transparent next step (“Clinician-led weight evaluation. See membership and medication costs.”)
- **Flag:** “You have low T / obesity / infertility…” (personal attributes)
- **Flag:** “Lose X lbs in Y weeks” without clinical substantiation + platform qualifiers
- **Flag:** sexual enhancement framing for ED/menopause (health-efficacy framing only, 18+)
- **Flag:** research/RUO label with human checkout
- **Required when promoting Rx (Meta):** consult licensed professional / valid prescription language per current policy
- **Price:** “from $X” needs qualifying tier + meds/labs/shipping exclusions nearby
- Disclaimers do not cure false or restricted claims

## Visual rules (HOUSE + PLATFORM)
- Brand-first first frame when branded; one composition; no hero badge clutter
- Prefer real practice/process imagery over lab spectacle
- Default **no** medical/weight-loss before-after pending specific review (Meta allows some cosmetic B/A 18+; Rx weight follows Drugs policy—do not conflate)
- No fat-pinching, appearance inferiority, needle gore shock hooks
- No fabricated patients/clinicians; talent releases required
- Logo: PNG/JPG/WebP for MyDose uploads; **no SVG** to Studio (4 MB cap)

## Variant matrix (produce intentionally)
For each concept ship: (1) service-only, (2) offer-clarity, (3) Rx-aware **only if certified**. Never “one creative for all platforms.”

## Audit output
Exact excerpt → taxonomy → current source URL/date → rewrite → PASS/REVISE/BLOCKED. Re-audit full assembled asset + destination. Thumbnails, crops, subtitles = new variants.

## Cross-skills
After creative draft → clinical-claims → legitscript-ads-gate → meta **or** google-youtube filter → audience-targeting → client/state → publication gate.
