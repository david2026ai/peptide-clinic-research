# Plain-name brand system

House style: a stranger understands the name in one second of a video ad. **Formula: [what the buyer is shopping for] + [trust noun]** (Counsel, Experts, Guide, Team, Care). Examples: Car Accident Counsel, Helpful Hacks, Longevity Care Experts.

## Generate

Produce 10–15 candidates across 3 trust nouns, then shortlist 5 in a table: name · domain · strength · risk.

## Screen (every candidate)

1. Search the exact name + category for existing businesses; drop close matches in the same field.
2. Check outcome words — none allowed in health names (see `longevity-claims-guard`).
3. "Doctors"/"MD" only if physicians deliver the care.
4. Keep regulated verticals separate: do not reuse a word that ties a health brand to a legal brand (e.g. "Counsel"), so enforcement in one cannot spill to the other.
5. Flag that descriptive names are weak trademarks; protect the logo, colors and video style instead.
6. Mark every domain "unchecked" until a registrar confirms it.

## Build the identity

- Wordmark first (the name is the logo), plus a simple monogram for avatars and favicons.
- Palette: one deep anchor, one warm neutral, one restrained accent; check text contrast ≥ 4.5:1.
- Type: an authoritative display face + a clean sans for body.
- Deliver on a design canvas: logo lockups, palette, type, a video end card and a landing hero.
