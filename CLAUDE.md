## Workflow Order (Always Follow)
1. Fill `templates/clinic-context.md` with real clinic details before any drafting.
2. Strategy → website copy + 7 editing sweeps **OR** video-creative workflow → clinical-claims filter → platform filter(s) → state/legal review → human publication gate.
3. Use `templates/campaign-brief.md`, `templates/claims-register.md`, `templates/audit-report.md`, `templates/release-checklist.md`.
4. Internal PASS ≠ permission to publish. All external tracks (clinical, legal, privacy, platform) start PENDING.

## Hard Rules
- No patient data, credentials, or account IDs in this folder.
- No publishing, ad spend, or live-account changes without explicit separate authorization.
- No guaranteed eligibility, diagnosis by quiz, therapeutic guarantees, or fabricated patient/clinician.
- Translations, thumbnails, and generated visuals are new reviewable variants — re-audit each.
- Refresh primary sources before each audit; log access date, effective date, and exact excerpt.

## Internal Verdict Taxonomy
- **PASS** — no issue found in scope/evidence as of stated date. Not legal clearance.
- **REVISE** — remediable problem with exact excerpt + proposed rewrite.
- **BLOCKED** — material evidence/authority missing or impermissible channel. Cannot be softened.
